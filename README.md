## Cloning this repo

Large assets (`reicon.js`, the pitch deck) are stored with Git LFS. Install LFS
**before** cloning, otherwise those files arrive as small pointer stubs and the
prototype renders without icons:

```
git lfs install
git clone <this repo>
```

The Android WebView wrapper is developed alongside this prototype but is not
tracked here; see `Sukinnect-Android/` locally.
